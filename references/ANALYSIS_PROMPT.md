# AI 组合分析报告

用本次快照解释组合的收益来源、风险和分散化效果。先写 2–4 条核心发现，再按对本组合最重要的业务问题展开正文，章节和顺序随证据调整。主要章节都在 `paragraphs` 写 1–2 个短段，每段 2–3 句为宜。可用 `reading_title` 提炼该段正文的判断。先给出判断，挑出最有解释力的对照数据，再说明它对组合意味着什么。图表或表格支撑判断，正文负责解释差异和权衡。已有结论和数字只在有助于展开分析时重述。中文日期和百分比连写，例如「6月30日」和「21.57%」。

## 业务分析

- **收益是怎么形成的**。结合回顾期收益、基准和累计曲线，挑出有代表性的转折或阶段。说明超额何时扩大或收窄，区分期末收益和实际持有路径。只有波动、回撤、夏普和收益的窗口可比时，才据此评价获得收益所承担的风险。
- **哪些持仓在拉动收益，哪些在放大风险**。用回顾期贡献找主要正向来源和抵消项，用当前权重和固定份额回溯找主要波动来源。风险贡献占比和权重可以按各自含义并列解释。跨窗口的收益贡献和风险贡献分开解读，禁止据此计算性价比或把结果归因到某次调仓。
- **表面分散之后还有哪些共同敞口**。结合持仓权重、穿透地区或行业、两两相关性，看不同基金是否暴露于相似风险。区分相关性、风险贡献和行业持仓证据，只在证据支持时串联这些观察。相关系数接近零时，只能说明该样本期内的线性联动较弱。
- **组合层面最值得关注什么**。用结尾提炼一项收益特征和一项主要风险，说明哪个观察最可能影响对组合的判断。省略缺乏证据的维度。

## 数据与展示边界

- 适合对照的数据使用同一时间窗口、分母和单位。收益率、超额收益率、收益贡献、年化波动率贡献及占比统一用「%」展示。超额收益率按同期组合收益率减对比指数收益率计算。区分含交易的回顾结果、当前配置及固定份额回溯。单独解释非QDII和QDII行业。缺失值使用模板占位，只有确实影响某条结论时才在该条正文中说明，禁止编造或把空值当零。
- 分析限于本次快照与用户问题。仅在用户要求时加入有可靠来源的外部背景。区分观察与推断，保持风险管理视角，不作行情预测或买卖建议。
- 图表优先使用本次阅读视图的「本次可用图表」。按需要选 2–5 张并放在对应章节，也可用自选图表并为每个数值引用实际字段。页首复用数据报告的数据说明。正文、表格和图表均不添加独立的脚注、图注、口径说明或补充说明。需要交代的日期或窗口写在标题括号内，例如「持仓权重（截止2026-11-09）」或「年化波动率贡献（近一年）」。
- 每条发现和章节至少引用一个真实、非空的快照指针。正文不用插入指针。两份报告正文和证据展示不出现具体数据服务机构名称。数字常规显示两位小数。

## 提交格式

顶层包括 `title`、`findings`、`sections`、`conclusion`。发现需要 `title`、`conclusion`、`evidence`，可选 `highlights` 和 `risk_impact`。章节需要 `title` 和 `evidence`，内容从 `charts`、`paragraphs`、`tables` 中按需选用。有正文的章节可选 `reading_title`。表格为 `{"headers":[...],"rows":[...]}`。章节名称与顺序自定。

- 预设图表示例为 `{"id":"trend"}`。可用的 ID 以阅读视图为准。覆盖 `title` 时，保留需要说明的日期或窗口。
- 自选图用 `type: "bar"` 或 `type: "grouped"`，提供 `title`、`unit` 和 1–12 个 `rows`。分组图另需两个 `labels`。每行给出 `label` 和 `values`，单系列引用一个值，分组图按图例顺序引用两个值。数值由程序读取，空字符串单位表示无量纲。
- 自选图表示例仅用于展示结构，提交时替换指针、字段和名称为本次真实数据。

```json
{
  "type": "bar",
  "title": "主要基金持仓权重",
  "unit": "%",
  "rows": [
    {
      "label": "基金简称",
      "values": [{"pointer": "#/data/3/items/0", "field": "currentHoldingWeight"}]
    }
  ]
}
```
